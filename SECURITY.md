# Security policy

## Reporting a vulnerability

Please do not post credentials, private audio, exploit details, or other sensitive material in a public issue.

For a suspected vulnerability, open a minimal GitHub issue that describes the affected component and requests a private follow-up channel. For ordinary bugs that do not contain sensitive information, use the public issue tracker.

## Scope

Security reports should identify the Remixer version, operating system, and the smallest reproducible description possible. Third-party runtimes, models, and services keep their own security and disclosure policies.
